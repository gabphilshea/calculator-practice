# Calculator Program

A simple calculator web app built for practice, following [AsmrProg's]([https://www.youtube.com/@asmrprog7180](https://youtu.be/sBJmRD7kNTk?si=bIgd3CnuTTbSxOBQ)) tutorial to learn HTML, CSS, and JavaScript DOM manipulation.

## About

This project was built as a hands-on exercise to practice:
- Structuring a web page with HTML
- Styling UI elements with CSS
- Handling button clicks and calculator logic with JavaScript
- Manipulating the DOM to update the display in real time

## What I learned
- How to connect HTML buttons to JavaScript functions
- Basic event handling (`onclick`, event listeners)
- Managing state (current input, previous input, operator) in vanilla JS
- Formatting numbers for display

## What I changed from the original
- Colors
- Added background image
- Minor design touches

## Tech Stack
- HTML
- CSS
- JavaScript

## How to run
1. Clone this repo
2. Open `index.html` in your browser
